# Create a development company

{: .label .label-yellow }
Placeholder

Integration development needs its own tracezilla company (team) that contains
no customer or production data. Seed scripts and write workflows create
partners, SKUs, and orders, and they must never run against a live team.

This page assumes that you already have a tracezilla user account.
