# Experimental implementations

{: .label .label-yellow }
Experimental

These Shopify examples demonstrate how the same integration architecture can
be expressed in other languages and tools. They are useful references, but PHP
is the current maintained implementation and receives new workflows first.

Experimental means:

- new PHP commands may not yet exist here;
- API behavior and mappings may not have received the latest sandbox testing;
- documentation may lag behind the maintained PHP implementation;
- consultants must review and test the code before using it for customer data.

## Available implementations

- [TypeScript](../shopify/typescript.html)
- [Python](../shopify/python.html)
- [Ruby](../shopify/ruby.html)
- [C# / .NET](../shopify/dotnet.html)
- [Java](../shopify/java.html)
- [Make.com](../shopify/make.html) — planned material only

For current, consultant-ready development, start with
[Shopify and PHP](../shopify/php.html).
