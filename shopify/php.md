# Shopify with PHP

{: .label .label-yellow }
Planned

The framework-neutral
[`tracezilla-shopify-php`](https://github.com/Happy-Bananas/tracezilla-shopify-php)
repository has been created. Its examples will cover verified catalog,
inventory, and order workflows using Composer and ordinary PHP without an
application framework.

## Optional Laravel workbench

The [`tracezilla-integration-workbench`](https://github.com/Happy-Bananas/tracezilla-integration-workbench)
is a Laravel application for validating credentials and safely trying selected
workflows. It is a supporting tool, not the canonical PHP template.
