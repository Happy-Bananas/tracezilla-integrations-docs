# Getting started

Choose the external service first, then either choose a workflow or an
implementation platform.

```text
Maintained:   Shopify → PHP → Compare Catalogs
Experimental: Shopify Labs → TypeScript → Compare Catalogs
```

Each workflow explains purpose, data direction, customer decisions, safety,
and expected results. Each platform example explains how to install, run,
verify, and adapt one concrete implementation.

Start with a read-only comparison or dry run. Review identity, units,
locations, source-of-truth rules, and recovery behavior before enabling any
write operation.
