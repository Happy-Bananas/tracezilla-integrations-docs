# Implementations

Choose the maintained headless PHP application unless a project specifically
requires another language. Each repository is independent; clone only the
implementation you need.

## Primary implementation

- [PHP integration with Shopify](https://github.com/Happy-Bananas/tracezilla-shopify-php)
  — the standalone headless application, programmable PHP scenarios, console
  commands, cron safety, retries, and history.

## Additional PHP implementation

- [PHP integration with WooCommerce](https://github.com/Happy-Bananas/tracezilla-woocommerce-php)
  — framework-neutral WooCommerce console integration under development.

## Shopify language examples

These repositories demonstrate the same integration boundaries in other
languages. Their workflow coverage may differ from the primary PHP project.
